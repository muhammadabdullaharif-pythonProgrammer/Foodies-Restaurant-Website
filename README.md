Foodies - Restaurant & Food Delivery Website 🍕
A modern, fully responsive restaurant and food delivery website built with HTML5, CSS3, Bootstrap 5, and JavaScript. Features an elegant design with interactive elements and smooth animations.

✨ Features
🎨 Design & UI/UX
Modern & Clean Design - Professional restaurant website layout

Fully Responsive - Mobile-first approach with perfect display on all devices

Smooth Animations - CSS transitions and JavaScript animations

Professional Color Scheme - Carefully selected color palette for food industry

Google Fonts Integration - Roboto and Quicksand fonts for better typography

🍽️ Restaurant Features
Interactive Food Menu - Beautiful food cards with pricing and descriptions

Food Categories - Organized menu with categories (Popular, New, Featured)

Pricing Display - Clear pricing with discount badges and original prices

Add to Cart - Interactive order buttons with feedback

Favorites System - Add items to favorites functionality

🔧 Technical Features
Bootstrap 5 Integration - Modern framework for responsive design

Font Awesome Icons - Professional iconography throughout

Smooth Scrolling - Seamless navigation between sections

Counter Animation - Animated number counters for statistics

Testimonial Carousel - Bootstrap carousel for customer reviews

Newsletter Subscription - Email subscription with validation

FAQ Section - Collapsible frequently asked questions

📱 Mobile Optimization
Hamburger Menu - Collapsible navigation for mobile devices

Touch-Friendly - Optimized for touch interactions

Fast Loading - Optimized images and code for performance

Cross-Browser Compatible - Works on all modern browsers

🛠️ Technologies Used
Frontend Framework: Bootstrap 5.0.2

Styling: CSS3 with CSS Variables

Scripting: Vanilla JavaScript + jQuery

Icons: Font Awesome 6.4.0

Fonts: Google Fonts (Roboto, Quicksand)

Responsive Design: Mobile-first CSS

Animation: CSS Transitions & Keyframes
